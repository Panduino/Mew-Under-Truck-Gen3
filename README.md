# Mew Under the Truck

Turn one of Pokémon's oldest playground rumors into a real FireRed and LeafGreen event.

After becoming Champion, you can return to the S.S. Anne area and ask the sailor to take you back to the abandoned dock. Explore the dock, find the famous truck, and interact with it to encounter a **Level 50 Mew**.

The normal Sevii Islands ferry remains available, so the event fits alongside FireRed and LeafGreen's existing postgame travel.

## Features

- Post-Champion Mew encounter at the S.S. Anne truck
- Restores access to the otherwise abandoned dock
- Sailor lets you choose between the dock and normal Sevii travel
- Mew remains available until it is successfully caught
- Designed as a small, self-contained postgame event
